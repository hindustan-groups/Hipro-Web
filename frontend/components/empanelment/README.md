# Public Empanelment Portal UI Components

This directory houses the modernized, mobile-friendly components for the Public Vendor Portal (`/empanelment`):
- `EmpanelmentWizard/`: 5-Step guided application flow with camera auto-compression
- `GstVerifier/`: Live GSTIN state/entity/PAN auto-decoder
- `VendorIdCard/`: SVG Smart PVC Card with dynamic QR verification
- `GatePass/`: Daily 24-hr site access pass generator
- `EligibilityCalculator/`: Interactive turnover and experience grading engine
- `ActiveTenders/`: Live tender discovery and digital bidding cards
- `DossierViewer/`: Printable multi-page A4 application dossier
