# Master Admin Empanelment Suite Components

This directory houses the administrative management modules for `/admin/empanelment`:
- `AdminEmpanelmentOverview.tsx`: KPI counters, verification pipeline overview, urgent actions
- `AdminEmpanelmentApplications.tsx`: Application audit table, search, category filter, verification drawer
- `AdminEmpanelmentVendors.tsx`: Verified vendor directory, Class A/B/C tiering, printable ID card & dossier
- `AdminEmpanelmentTenders.tsx`: Tender creation, publishing, EMD and deadline controls, bid reviews
- `AdminEmpanelmentGatePasses.tsx`: Daily site security logs, QR gate pass verification
- `AdminEmpanelmentInvoices.tsx`: Vendor billing, TDS deduction, milestone payout tracking
- `AdminEmpanelmentSettings.tsx`: Eligibility scoring weights, category management, staff delegation
