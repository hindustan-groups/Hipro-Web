# Empanelment Backend Controllers

This directory houses the controllers for `/api/empanelment/*`:
- `applications.controller.ts`: Application submissions, status pipeline updates, digital grading
- `tenders.controller.ts`: Tender publishing, document downloads, vendor bid evaluation
- `gatepass.controller.ts`: Daily 24-hr gate pass generation & QR verification
- `workorders.controller.ts`: Work order issuance, milestone tracking
- `invoices.controller.ts`: Invoice submission, payment approval, RTGS tracking
- `tickets.controller.ts`: Vendor support inquiries & helpdesk responses
